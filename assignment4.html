系统定义（沿用作业 1 / 2 / 3）System of Interest

面向高阶智能驾驶的线控底盘系统，是以电信号传递控制指令、分布式执行器独立驱动为核心，集成线控转向（SBW）、线控制动（BBW/EHB/EMB）、线控驱动协调、悬架与车身姿态控制等子系统，并由底盘域控制器完成信号融合、整车动力学协调与安全监控的底盘执行层系统。上层智驾算法给出纵向加减速、横向转角与车身稳定性目标，线控底盘将其实时、精确、安全地转化为车轮与路面的力与运动。

边界：感知与决策算法（摄像头、雷达、规控模型）属于智驾域，不在本系统内部；本系统只对「控制指令的接收—解析—协调—执行—状态反馈」负责。因此本页 ODD 描述以底盘执行所需条件为视角：外部环境决定轮胎附着与可控裕度，内部系统状态决定执行能力，人员状态决定人机交接前提。

术语与参考依据 ODD / ODR

  • ODD（Operational Design Domain，设计运行条件）：系统被设计为可正常运行的一组运行条件，涵盖环境、道路、交通、人员、系统状态等方面，对齐 ISO 34503 与参考资料《智能网联汽车 自动驾驶系统设计运行条件 v1.0》。
  • 运行设计范围：系统允许工作的外部边界（道路、路面、天气、光照、气温、速度等）。
  • 系统状态：系统内部完成执行任务所必须满足的健康、供电、通信、传感器与冗余条件。
  • 人员状态：驾驶员 / 动态驾驶任务后援用户及乘客的注意力、位姿、安全带与干扰状态。
  • 参考标准：CJJ 37-2012《城市道路工程设计规范》、JTG D20《公路路线设计规范》、GB 5768.2/.3《道路交通标志和标线》、GB/T 35663-2017《天气预报基本术语》、GB/T 918.1/.2《道路车辆分类与代码》、ISO 26262、ISO 21448。

按作业要求，运行设计条件分为三部分：运行设计范围（外部环境边界）、系统状态（内部依赖条件）、人员状态。下表给出线控底盘系统正常运行的允许条件与边界；表中定量阈值为平台示例值，最终以整车标定与企业技术规格为准。

3.1 运行设计范围 Operational Design Range · 外部边界

要素类别要素允许的设计运行范围（示例）不允许 / 边界条件
道路类型城市道路城市快速路、主干路；次干路 / 支路在限定车速与交通复杂度下允许无标线路段、极度混行的狭窄支路不允许全自动运行

停车区域铺装良好的室内 / 室外停车场，平行、垂直、斜列车位低速泊车机械立体车库、非铺装场地泊车不允许（按平台能力声明）

3.4 越界处置原则 Out-of-ODD Handling

  • 进入边界前预判：依据地图、定位与环境感知预判前方道路 / 天气 / 交通将超出 ODD，提前提示并准备交接或限速。
  • 超限即时限制：运行中条件超出 ODD 时，底盘首先限制控制输出在附着与能力包络内，避免强行执行越限指令。
  • 分级降级：按内部故障与环境偏离程度分级：功能受限运行 → 提示接管 → 最小风险状态（MRC，如限速蠕行、靠边停车）。
  • 状态回传：越界原因、当前降级状态与可执行能力须向智驾域 / HMI 回传，保证上层决策与驾驶员可知。

4.3 底盘控制任务时序 Control Timeline

t0 巡航阶段
稳定跟车：底盘按目标车速 / 车距维持轻微驱动与制动调节，悬架保持平直姿态，转向保持车道居中；各信号与执行器状态正常。
t1 风险识别
指令下达：智驾域发出目标减速度（紧急制动请求）与必要时的目标转角 / 横摆角速度请求；底盘域控制器完成指令合法性、附着裕度与能力包络校验。
t2 制动建压
纵向执行：线控制动快速建压，按目标减速度闭环减速；驱动侧退出扭矩并协调能量回收；ABS 监控车轮滑移率，防止抱死。
t3 横向协调
转向 / 稳定：如需避让，线控转向按目标转角闭环动作；ESC / 稳定控制在横摆与侧滑边界内协调各轮制动力与扭矩，防止转向过度 / 不足；悬架抑制制动俯仰与转向侧倾。
t4 减速收尾
停车或恢复：接近前车后平稳降至停车或恢复跟车距离；控制量平滑退出，避免末端抖动与突兀再加速；状态与健康度回传智驾域与 HMI。

子系统场景中的动作关键约束 / 目标

4.5 成功判据 Success Criteria

  • 车辆在本车道内以可控方式减速，避免与前车碰撞；具备避让条件时，绕行轨迹不侵入相邻车道安全边界。
  • 全过程车轮不抱死、不出现不可控侧滑 / 甩尾；横纵向加速度处于稳定包络内。
  • 制动与转向动作平顺，无控制阶跃、无异常抖动；减速结束后可平稳恢复跟车或安全停车。
  • 关键指令、执行状态与故障事件被记录，支持事后追溯与诊断。
