系统定义（沿用作业 1 / 作业 2）System of Interest

面向高阶智能驾驶的线控底盘系统，是以电信号传递控制指令、分布式执行器独立驱动为核心，集成线控转向（SBW）、线控制动（BBW/EHB/EMB）、线控驱动协调、悬架与车身姿态控制等子系统，并由底盘域控制器完成信号融合、整车动力学协调与安全监控的底盘执行层系统。它是高阶智能驾驶（L2+ 至 L4）的执行底座：上层智驾算法给出纵向加减速、横向转角与车身稳定性目标，线控底盘将其实时、精确、安全地转化为车轮与路面的力与运动。

边界：感知与决策算法（摄像头、雷达、规控模型）属于智驾域，不在本系统内部；本系统只对「控制指令的接收—解析—协调—执行—状态反馈」负责。

需求追溯关系 BRS/StRS → SyRS

作业 2 输出的 10 条相关方需求（SR-01 ~ SR-10）是本 SyRS 的直接输入；系统需求由相关方需求经分解、预算分配与继承转换而来，每条系统需求均标注其上游 SR 编号，保证双向可追溯。

01

系统需求规格书（SyRS）

对应参考资料表 5-1《ISO/IEC/IEEE 29148:2018 标准中的 SyRS 范例》。SyRS 从方案域以系统视角定义高层次技术需求，描述系统「将做什么」、与外部环境的交互及接口，不规定具体实现。

1.1简介 · 系统目的

线控底盘系统的目的是接收智驾域（或驾驶员）的运动控制指令，实时、精确、安全地完成车辆纵向、横向与垂向运动控制，使高阶自动驾驶决策能够闭环作用于车辆物理运动，并在正常与失效工况下维持车辆基本可控。具体目标：

  • 为 L2+ 至 L4 级自动驾驶提供可由算法直接控制的转向、制动、驱动执行接口；
  • 将上层目标（目标加速度、目标转角、目标横摆角速度、目标姿态）稳定、精确地落到车轮与路面；
  • 通过冗余与降级，在主通路失效后保持最低可接受的操控能力与安全停车能力。
1.2简介 · 系统范围
  • 在范围内：底盘域控制器软硬件；线控转向、线控制动、驱动协调、悬架姿态四个执行子系统；与智驾域 / 动力域 / 电源域 / HMI / 车云的接口；台架与整车标定验证、量产装车与售后保障。
  • 范围以外：感知传感器、自动驾驶规控算法本体、车身内外饰、轮胎与整车总布置（由其他系统负责，本系统通过接口协同）。
1.3简介 · 系统概况

系统以底盘域控制器为协调核心：向上通过车载总线 / 以太网接收智驾域目标指令与驾驶员操作、接收动力域与电源域状态；向下驱动四个执行子系统完成转向、制动、驱动与姿态动作；同时采集轮速、转角、压力、姿态等信号形成闭环，并向整车与智驾域回传执行状态与健康度。

1.4简介 · 系统环境
  • 运行环境：城市道路、高速公路、停车场、低附着（湿滑 / 冰雪）路面、颠簸路面；冷热气候、高低电压、正常与老化载荷。
  • 互操作环境：智驾域控制器、整车控制器 VCU、动力域 / BMS、HMI 仪表、车云后台与 OTA / 诊断系统。
  • 物理环境：道路附着条件、交通参与者与信号、环境温度 / 振动 / 电磁干扰、轮胎状态与老化。
1.5简介 · 系统功能

系统总体功能 F0：把上层运动目标闭环转化为车辆可控的力与运动。分解为指令接收与解析、状态采集与融合、协调控制量分配、执行器驱动、反馈闭环、安全监控与降级六组功能（详见第 02 章功能架构）。

1.6简介 · 用户特征
  • 直接使用方：驾驶员 / 车主（手动模式操作与体验）、智驾系统（自动控制方，非自然人使用者）。
  • 使能方：标定与测试人员、售后维修人员、系统开发与质量安全团队。
  • 特征：驾驶员关注操控跟手性与接管平顺性；智驾系统要求接口标准化、时序确定；售后要求可诊断、可维护。
2定义
  • 线控（X-by-Wire）：以电信号代替机械 / 液压硬连接传递控制指令，由独立布置的执行器完成转向、制动等动作。
  • SBW / BBW：线控转向 / 线控制动；EHB 为电子液压制动，EMB 为电子机械制动。
  • 冗余与降级：主通路失效后由备份通路维持基本可控；降级指部分功能受限条件下保证安全行驶。
  • 最小风险状态（MRC）：系统失效后车辆应进入的安全可控状态（如靠边停车 / 限速蠕行）。
  • UCA：不安全控制动作（Unsafe Control Action），STPA 分析的核心识别对象。

4 系统需求 4.1 功能需求

FR-01高功能
系统应接收并解析智驾域目标指令（目标加速度 / 减速度、目标前轮转角、目标横摆角速度、目标车身姿态）与驾驶员操作信号，完成合法性校验后送入协调控制。
智驾闭环依赖底盘可被算法控制，非法或越限指令必须被拦截。
追溯：SR-02 · SR-01
FR-02高功能
系统应采集轮速、方向盘转角 / 扭矩、齿条位移、制动压力、电机电流、车身姿态与电源电压等信号，融合估计车辆状态与路面附着条件。
协调控制与防滑、稳定控制都依赖状态与附着估计。
追溯：SR-05 · SR-06
FR-03高功能
系统应在纵向（驱动 / 制动）、横向（转向）、垂向（悬架）之间协调分配控制量，使合成控制不超出轮胎附着极限，防止打滑与失控。
极限与低附着工况下需在附着力范围内分配控制量。
追溯：SR-05 · SR-01
FR-04高功能
线控转向子系统应按目标转角闭环驱动转向执行电机，提供模拟路感反馈，并支持低速大转角泊车与高速转向稳定。
横向控制是高阶智驾轨迹跟随的执行基础。
追溯：SR-01 · SR-04
FR-05高功能
线控制动子系统应按目标减速度 / 制动压力闭环建压，支持常规制动、主动紧急制动、ABS / ESC 协调与能量回收协调。
纵向减速与主动安全依赖制动执行。
追溯：SR-01 · SR-05
FR-06中功能
线控驱动协调应响应电机扭矩请求，完成驱动防滑与扭矩矢量分配，并与动力域协调能量回收。
纵向加速与稳定需要驱动侧配合。
追溯：SR-05
FR-07中功能
悬架姿态协调应根据工况调节阻尼与车身高度，抑制俯仰 / 侧倾，并与转向、制动动作协同。
垂向姿态影响乘坐舒适与稳定裕度。
追溯：SR-04
FR-08高功能
系统应在自动 / 手动模式之间平滑融合或交接控制指令，交接过程不产生控制阶跃与抖动。
人机共驾要求接管平顺、可感知。
追溯：SR-04
FR-09高功能
系统应持续监控输出合理性与通路健康，主通路失效时切换备份通路或进入受限降级，并按分级规则告警。
单一失效防护是法规与功能安全要求。
追溯：SR-03
FR-10中功能
系统应记录关键控制动作、故障事件与软件版本，提供标准化诊断接口，支持下线检测、售后维修与故障追溯。
测试与售后依赖数据定位问题，关键事件须可追溯。
追溯：SR-06 · SR-07

4.2 可用性需求 Availability / Reliability

UR-01高可用性
关键行驶功能应高可用，平均无故障时间（MTBF）达到企业质量目标；安全相关功能按 ISO 26262 功能安全等级（ASIL）设计与验证。
行车安全与企业质量目标要求。
追溯：SR-01 · SR-08
UR-02中可用性
系统在规定环境范围内应持续可用；超出环境边界时进入保护 / 降级状态，而非异常失效或无响应。
环境超限是现实工况，需要可预期的保护行为。
追溯：SR-08
UR-03中可用性
系统应可维护、可升级：故障可定位、执行器可替换，标定与软件版本可管理升级并支持一致性校验与回退。
平台化迭代与售后要求版本可控。
追溯：SR-06 · SR-07

5 系统运行

5.1系统模式与状态
  • 下电休眠 / 上电自检：控制器休眠待命；上电完成自检、冗余通路确认与就绪判定。
  • 手动驾驶模式：响应驾驶员操作，提供转向助力、制动助力与稳定支持。
  • 自动驾驶模式：接收智驾目标，闭环执行转向、制动、驱动与姿态控制。
  • 接管 / 混合模式：人机权限过渡，指令按规则融合或平滑切换。
  • 冗余降级模式：主通路失效后备份通路工作，功能受限但保持可控并告警。
  • 驻车保持：驻车制动保持，下电前完成状态存储。
5.2物理特征
  • 执行器分布式布置于转向机、制动总成、电机与悬架处；底盘域控制器集中布置。
  • 供电：12V / 48V 低压与高压驱动协同，关键安全件双电源。
  • 重量、安装接口、散热与空间随整车总布置约束，冗余件需独立安装位置。
5.3环境条件
  • 工作温度、湿度、振动、冲击与电磁兼容（EMC）范围按整车规范；超出范围进入保护 / 降级。
  • 防护等级适应底盘舱位泥水、粉尘环境；耐电压波动与抛负载。

6 安保需求 Safety & Security 防护

SEC-01高安保
关键控制通信应防非法篡改与注入，采用加密与消息认证；诊断与升级接口具备访问控制。
网络安全准入要求（ISO/SAE 21434），防止恶意误控。
追溯：SR-08
SEC-02高安保
所有控制输出须经合理性校验，越限 / 矛盾指令拒绝执行并上报，防止误触发。
防止错误或恶意指令直接作用于车轮。
追溯：SR-03 · SR-01
SEC-03中安保
执行器机械连接具备防误动与防护设计，防止装配 / 维修过程中非预期动作。
追溯：SR-06

7 信息管理需求

  • 统一底盘信号字典、标定数据与故障码组织规则；关键控制动作、故障事件与版本号须被记录并可追溯。
  • 升级前后版本一致性可校验；运行数据按隐私与合规要求存储、回传。

8 政策与法规需求

  • 满足转向、制动强制法规与整车准入要求；功能安全按 ISO 26262 完成 ASIL 分级与安全论证。
  • 预期功能安全按 ISO 21448（SOTIF）分析由感知 / 局限导致的危险场景；网络安全按 ISO/SAE 21434 落地。
  • 满足行业标准对失效告警、降级提示与驾驶员告知的规定。

9 系统生存周期支持需求 包装 / 处理 / 装载 / 运输

  • 执行器与控制器应可制造、可装配、可维修，关键件具备备选供应来源或风险预案。
  • 包装、搬运、装载与运输满足防震、防潮、防静电要求；报废后按法规回收拆解。
  • 预留向域集中 / 中央计算架构演进的接口与算力空间。

11 附录

11.1假设与依赖
  • 假设智驾域提供的目标指令在其自身功能边界内有效；感知 / 规控局限由 SOTIF 另行分析。
  • 依赖整车供电、车载网络与 E/E 架构提供符合指标的电源与通信通道。
  • 依赖执行器供应商按接口规范交付；关键性能定量指标在平台标定阶段最终确定。
11.2缩写与缩略语
  • SyRS：系统需求规格说明；SBW / BBW：线控转向 / 线控制动；EHB / EMB：电子液压 / 电子机械制动。
  • VCU：整车控制器；BMS：电池管理系统；HMI：人机界面；OTA：在线升级；ASIL：汽车安全完整性等级。
  • STPA：系统理论过程分析；UCA：不安全控制动作；MRC：最小风险状态；SOTIF：预期功能安全。
